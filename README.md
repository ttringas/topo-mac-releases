# Topo for Mac — Downloads

Public distribution point for **Topo for Mac**, the front-desk app for gyms that run on
[Topo](https://topoclimb.com): check-in, the barcode scanner, notifications and kiosk mode
in one app.

The source code lives in a private repo. This repo holds the signed, notarized release
builds and the Sparkle auto-update feed (`appcast.xml`).

## Install

1. **[Download Topo for Mac](https://github.com/ttringas/topo-mac-releases/releases/latest/download/Topo.dmg)**
2. Open `Topo.dmg` and drag **Topo** onto **Applications**.
3. Open **Topo** and follow the setup: sign in with your browser, pick this desk, and
   connect the scanner.

Topo updates itself automatically.
